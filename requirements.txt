# qlu-newsletter-tools — Python packages
# --------------------------------------
# New developer setup (Windows):
#   1. Install Python 3.10+ from https://www.python.org/downloads/
#      (check "Add python.exe to PATH")
#   2. From this folder:
#        python -m pip install -r requirements.txt
#   3. Start UI:
#        .\start.cmd
#
# System notes (not installable via pip alone):
#   • Captions (default Innertube engine) → stdlib only; no extra packages.
#   • Captions (--engine yt-dlp) / Extract frame → need packages below.
#   • Extract frame needs an ffmpeg binary. Prefer the imageio-ffmpeg bundle
#     (installed by this file). Optional system install:
#        winget install Gyan.FFmpeg
#     Or set FFMPEG_PATH / YT_DLP_PATH to custom executables.
#
# Optional CLI helpers (CMS / Astro must already be running):
#   import_theme_readmore.py          → local folder of .md (stdlib + Payload :3000)
#   import_theme_readmore_gdrive.py   → shared Google Drive folder (needs gdown)
#   import_theme_images.py            → local folder of frame JPGs → themeItems.image
#   import_theme_images_gdrive.py     → Drive folder of frames (needs gdown)
#   export_section_pages.py / export_print_snapshot.py → Payload :3000 / Astro :4321
# Drive folders must be shared as "Anyone with the link can view".
